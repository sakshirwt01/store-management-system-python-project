# 🏪 Store Management System (Python)

A simple **console-based Store Management System** built using Python.
This project allows users to manage customers, products, and orders efficiently using file handling.

## 🚀 Features

### 👤 Customer Management

* Add new customers
* View all customers
* Delete customers

### 📦 Product Management

* Add new products
* View all products
* Update product price

### 🧾 Order Management

* Place orders
* View all orders
* View orders by Customer ID

## 🛠️ Technologies Used

* Python 🐍
* File Handling (Binary Files)
* `pickle` module (for data serialization)
* `os` module (for file operations)

## ▶️ How to Run

1. Clone the repository:

```
git clone https://github.com/your-username/store-management-system-python.git
```

2. Navigate to the project folder:

```
cd store-management-system-python
```

3. Run the program:

```
python main.py
```
